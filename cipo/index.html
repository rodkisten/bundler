01 / TALK CSS
Semantic shorthands, not a new religion.
Keep authoring CSS-shaped code. Use compact property aliases where they help and raw CSS where they do not.
px: 4; bg: $brand; rounded: $xl;

        
02 / HELPERS
Functions with roots.
Color mixing, alpha, fluid sizing, gradients, shadows, token lookup and context values are resolved by the runtime helper registry.
bg: alpha($brand / 20%);

        
03 / VARIANTS
States stay beside the thing they mutate.
Hover, dark mode, breakpoints and container queries remain local and readable instead of scattering across files.
x:hover { transform: translateY(-4px); }

        
04 / NATIVE FIRST
The platform keeps the steering wheel.
Modern CSS functions pass through untouched. Cipó only intervenes when a registered helper, token or DSL feature actually needs resolution.
width: min(100%, 42rem);

        
05 / ATOMIC ENGINE
Reuse where reuse earns its keep.
Runtime JIT caching and reuse-aware atomic promotion keep repeated declarations compact without forcing every first-use style into an atomic class.
atomic.css`display:flex; gap:2;`

        
06 / STYLESHEETS
One runtime, multiple shapes.
Compile atomic declarations, complete stylesheets, scoped sheets or cascade layers through the same browser-first engine.
sheet.css.scoped('.app')`...`
