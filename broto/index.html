01

No virtual tree.

Dependencies are recorded where values are read. Updates travel through a graph instead of asking the whole interface to audition again.

02

Ownership is lifecycle.

Effects and resources belong to explicit owner scopes, so cleanup is not an afterthought hidden in a hook maze.

03

Deep state without Proxy magic tricks.

Stores expose signal-shaped leaves, snapshots and batched patches. You can inspect the machinery because the machinery is not pretending to be plain JavaScript.

const state = store({
  user: { name: "Rod" },
  panel: { open: false }
})

state.panel.open.set(true)
state.user.name.set("Rodolfo")

The whole mental model

Read. Derive. React. Dispose.

import { signal, computed, effect } from "@rodkisten/broto"

const count = signal(0)
const doubled = computed(() => count() * 2)

const dispose = effect(() => {
  console.log(doubled())
})

count.update(value => value + 1)
dispose()
