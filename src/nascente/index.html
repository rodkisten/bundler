Nascente

Utilitários que começam pequenos e correm rápidos. Uma API flat para hot paths, pensada para o bolso onde o JavaScript mais sofre: o celular.

A correnteza

Performance sem superstição.

01 · fewer allocations

Menos lixo no caminho

Transformações de uma passagem evitam pipelines de Object.entries().map() e arrays intermediários.

02 · predictable loops

WebKit-friendly

Loops indexados e estruturas previsíveis favorecem hot paths em Safari, especialmente sob pressão de memória.

03 · bounded async

Concorrência com margem

mapAsync e companhia limitam concorrência para não transformar uma lista em tempestade de promises.

Da fonte ao código

import { groupBy, mapValues, mapAsync } from "./nascente";

const teams = groupBy(users, user => user.teamId);
const scores = mapValues(rawScores, score => score * 2);
const profiles = await mapAsync(ids, fetchProfile, 4);

Regra da nascente: nenhuma utilidade é declarada universalmente mais rápida. Os benchmarks comparam workloads comuns; o TSDoc explica qual padrão cada função substitui e por que a implementação pode reduzir custo.
