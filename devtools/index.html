01 / Instrument rack

Eight tools. One page truth.

The dock is now a real mobile toolchain, not a console wearing a fake moustache. Every panel owns a focused debugging job and can hand nodes, requests and state to the others.

›_
Console

Native REPL + external streams

Console methods, groups, timers, object inspection, startup errors and DevTools.ingestLogs() with source badges. On iPhone the REPL falls back to a stable native textarea.

React

Fiber tree reconnaissance

Hooks, props, state, context, owners and DOM ↔ Fiber selection. Capture starts through the DevTools hook and falls back through DOM expandos, renderer APIs, globals, Shadow DOM, frames and bounded aggressive scans that only activate when React discovery runs.

03 / Public surface

      
Wire your tools straight in.

      
Userscripts and page tooling can feed Rod DevTools directly instead of proxying everything through the native console.


      

        

          
External console streamsource badge

          
const logs = DevTools.ingestLogs({
  source: "aio-downloader",
  badge: "wrk",
});

logs.info("media discovered", media);
logs.warn("fallback selected", strategy);
logs.error(error);

        

        

          
Intercept a console-like objectnative semantics

          
const stream = DevTools.ingestLogs(workerConsole, {
  source: "worker",
  badge: "W",
  passthrough: true,
});

stream.time("download");
stream.group("segment 42");
stream.table(rows);

05 / Field manual

      
One launcher. Several realities.

      

        
01
Document-start React
The generated userscript now starts at document-start, giving the React hook a chance to observe renderer injection before the app mounts.

        
02
Fallback ladder
React discovery escalates from the global hook to DOM expandos, containers, renderer host APIs, globals, Shadow DOM, same-origin frames and aggressive probes.

        
03
External log bus
Feed logs directly, create isolated streams or intercept console-like objects while preserving native groups, timers, counts and source badges.

        
04
Safari keyboard armor
16px real inputs, stable settings controls, VisualViewport batching and a native mobile REPL stop focus, caret and scroll from pinballing around iOS.

        
05
Stable dock shell
The tab strip and active panel occupy separate layout tracks, so Console cannot paint over the panel navigation when the viewport changes.

        
06
Early network capture
Network instrumentation is installed before the UI mounts so fetch/XHR bodies can still reach Network, Resources and Sources during startup.

        
07
Userscript factory
Export a document-start launcher with selected panels, React scanning budgets, theme, capture strategy and optional Eruda pairing.

        
08
Token machine
The laboratory itself remains controlled by semantic CSS custom properties for colors, borders, radius, noise, typography, motion and shadows.
