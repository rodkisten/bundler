A component that is already a DOM node.

No VDOM hand-off. No reconciliation universe between you and the browser. The template materializes into native nodes and reactive parts keep their exact subscriptions.

const count = signal(0)

render(host, html`
  <button @click=${() => count.update(n => n + 1)}>
    stamped ${count} times
  </button>
`)
